# Summarize Anything

Use when the user shares or links something long and wants the gist.

1. If they gave a link, open it with web search/fetch first; if you can't read it, say so — never
   summarize from the title alone.
2. Output, in this order:
   - **TL;DR** — 1–2 sentences.
   - **Key points** — 3–7 bullets, most important first.
   - **Action items / decisions** — only if the source contains them (who, what, when).
   - **Open questions** — anything the source leaves unclear.
3. Stay faithful: no outside facts, no opinions unless asked. Quote exact wording for anything
   sensitive (numbers, commitments, legal or medical statements).
4. Match length to the source: a one-page memo gets a short summary; a long report gets more.
5. Offer a follow-up: a shorter version, a version for a specific audience, or a deeper dive on one part.
