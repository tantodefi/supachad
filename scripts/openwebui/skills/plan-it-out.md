# Plan It Out

Use when the user has a goal, project, trip, event or habit and wants a plan.

1. Ask at most two quick questions if essential details are missing (deadline, budget, time per
   week). Otherwise state your assumptions and go.
2. Break the goal into 3–6 phases. For each phase give concrete steps that each take under a day.
3. Present a checklist the user can copy (Markdown `- [ ]` items), grouped by phase.
4. Add a timeline (by week or by date if a deadline was given) and mark the critical path.
5. Call out the 2–3 biggest risks or blockers and a fallback for each.
6. Finish with "Do this first:" — the single smallest next action, doable today.
7. Remember the plan in the user's memory only if they ask you to.
