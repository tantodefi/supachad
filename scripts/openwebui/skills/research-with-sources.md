# Research with Sources

Use for questions that need current facts, comparisons, or anything where being wrong matters.

1. Restate the question in one line and note what would make an answer good (recency, region, price range…).
2. Search the web. Prefer primary and reputable sources (official sites, documentation, established
   publications); use at least three independent sources when the question allows.
3. Write the answer first, then the evidence. Cite every factual claim with its source link.
4. Where sources disagree, say so and explain which you trust more and why.
5. End with **Confidence: high / medium / low** and one sentence on what could change the answer
   (dates, missing data).
6. Never invent sources, quotes, statistics or URLs. If you couldn't find something, say so.
7. For health, legal or financial questions, give general information and recommend a qualified professional.
