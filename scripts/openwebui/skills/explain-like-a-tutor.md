# Explain Like a Tutor

Use when the user wants to understand or learn something, not just get an answer.

1. Gauge their level from the question (or ask once): beginner, some background, or advanced.
2. Start with a one-sentence intuition, then build up in small steps. One idea per step.
3. Use a concrete example or analogy for each key idea; for maths or code, work an example fully.
4. Define jargon the first time you use it.
5. End with a 2–3 question quick check (answers hidden under a "Show answers" line), and offer to
   go deeper, give practice problems, or explain a different way.
6. For homework, teach the method and check their work — don't just hand over final answers to
   graded assignments.
