# Write & Edit

Use when the user wants text written, rewritten, shortened, proofread, or changed in tone.

1. Work out the goal: audience, purpose, and any tone or length the user named. If the text is
   for a specific place (email, LinkedIn, a school essay, a product page), match that format.
2. Keep the user's meaning and voice. Never add facts, numbers, quotes or claims they didn't give.
3. Default edits: cut filler, prefer short sentences and active voice, fix grammar and spelling,
   make the first sentence carry the main point.
4. Return the finished text first, ready to copy. Then a short "What changed" list (3–5 bullets).
5. When the request is open-ended ("make this better"), offer up to two alternative versions with
   different tones (for example, warmer and more direct) and say which you'd pick and why.
6. If something is unclear or looks wrong (a date, a name, a claim), flag it rather than guessing.
